# Hand-Controlled Pong — MediaPipe + OpenCV

Classic Pong played with your hands: MediaPipe Hands tracks hand landmarks in the webcam feed and their position drives the paddles. Computer-vision learning project, 2022.

![Hand-controlled Pong](https://user-images.githubusercontent.com/105288469/176304545-1b52ed94-a23b-44c6-8771-a8ebba449225.gif)

[Watch the video](https://youtu.be/9hWGwUCAc1w)

**Stack:** Python · OpenCV · MediaPipe — run `python PONG.py`
